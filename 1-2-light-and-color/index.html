光と色・ものが見えるしくみ

色は光から生まれます。可視光・物体の色・眼のしくみという「色が見える流れ」をたどります。

色は光がなければ存在しない 真っ暗な部屋では、どんなに鮮やかな服も色が見えません。色は光があってはじめて見えるからです。色が見えるまでには、「光源 → 物体 → 眼」という流れがあります。この章ではその流れを順番に確認します。 可視光：人の目に見える光 光は電磁波という波の仲間で、波の長さ（波長）によって性質が変わります。そのうち人の目に色として感じられる範囲を可視光といい、だいたい紫から赤までの範囲です。波長の短いほうが紫や青、長いほうが赤に対応します。 ・可視光より波長が短い側には紫外線（目には見えない） ・可視光より波長が長い側には赤外線（目には見えない） 太陽の光（白色光）はさまざまな波長の光が混ざったもので、プリズムに通すと虹のように分かれます。これを分光といい、どの波長の光がどれだけ含まれるかを表したものが分光分布です。 物体の色は「反射した光」の色 りんごが赤く見えるのは、りんご自身が赤く光っているからではありません。当たった光のうち赤い波長の光をよく反射し、それ以外を吸収しているため、反射した赤い光が目に届いて赤く見えます。 物体に当たった光は、おもに次の3つの運命をたどります。 ・反射 … はね返る（その色が見える） ・吸収 … 物体に吸い込まれる（見えない） ・透過 … 通り抜ける（ガラスなど） 「物体そのものに色がついている」と考えがちですが、正しくは「物体がどの波長を反射・透過するかで色が決まる」です。だから光源が変われば色の見え方も変わります。 眼のしくみ：錐体と桿体 反射した光は眼に入り、網膜にある視細胞が受け取ります。視細胞には2種類あります。 ・錐体（すいたい） … 明るい所ではたらき、色を見分ける細胞。赤・緑・青あたりに反応する種類がある ・桿体（かんたい） … 暗い所ではたらき、明暗を感じる細胞。色の判別は苦手 夜の薄暗がりで色が分かりにくくなるのは、色を感じる錐体が働きにくく、明暗を感じる桿体が中心になるためです。「明るい所＝錐体＝色」「暗い所＝桿体＝明暗」とセットで覚えましょう。 こうして「光源の光 → 物体での反射・吸収・透過 → 眼の視細胞 → 脳」という流れを経て、私たちは色を感じています。色は光・物体・眼の三者がそろって生まれるものなのです。

このモジュールのまとめ

  • 色は光があって見える。流れは「光源 → 物体 → 眼」
  • 可視光は人の目に見える波長の範囲。短い側が紫・青、長い側が赤
  • 物体の色は、当たった光をどの波長で反射・吸収・透過するかで決まる
  • 錐体は明るい所で色を、桿体は暗い所で明暗を感じる
